# 考研政治背诵模块：已实现说明

> 上线地址：`https://halfman.top/politics/`
> 初试日期：2026-12-19（北京时间）。首页倒计时已按这个日期修正。
> 计划范围：2026-11-06 → 2026-12-06，共 31 天。12-07 之后由你自己续排，页面仍会按到期队列继续复习。

## 1. 这个模块是什么

它不是把 PDF 做成电子书，而是一个“遮住答案的回忆训练器”。

- 以《27 考研政治一页纸·知识点手册》（澄潇宇）为蓝本，把 100 个知识点拆成 164 张学习卡。
- 每张卡先只给标题/首字提示，你先主动回忆 A→B 对应，再揭晓原书彩色关键词。
- 不要求逐字背。重点看红/橙/蓝/紫色关键词、会议与土地政策、统一战线等高频专题；灰色解释只在看不懂时展开。
- 进度、收藏、错题、笔记都存在浏览器 `localStorage`，不上传服务器；换设备前用“进度 → 导出记录”备份 JSON。

## 2. 页面结构

| 页签 | 用途 |
| --- | --- |
| 今日 | 今天该背哪一页、多少张卡、预计用时；一个“开始今天”按钮 |
| 背卡 | 164 张卡按板块/状态筛选，可单张背或整组背 |
| 查考点 | 搜“遵义会议 / 统一战线 / 土地政策 / 剩余价值”等，直接看原书卡片 |
| 专题 | 按马原、史纲、毛中特、会议大观、其他分板块，按 topic 分组 |
| 进度 | 31 天计划、近 7 天复习量、分板块掌握度、导出/导入/清空 |

复习会话的键盘操作：

- `Space` / `Enter`：揭晓答案
- `H`：看首字提示
- `1` / `2` / `3` / `4`：忘记 / 模糊 / 记得 / 熟练
- `Esc`：退出本轮

评分对应间隔：忘记→今天再来；模糊→至少 1 天；记得→升一档；熟练→升两档。临近考试会自动把最大间隔压到 14 天、7 天、3 天。

## 3. 31 天计划（11-06 → 12-06）

第一轮按 PDF 页码走，每天 1 页；第二轮用 6 天回炉 p11–p22。每天约 30–40 分钟。

| 日期 | 页码 | 内容 |
| --- | --- | --- |
| 11-06 ~ 11-17 | p11–p22 | 马原（p11–p17）；史纲开端（p18–p22） |
| 11-18 ~ 11-25 | p23–p30 | 史纲后半 + 毛中特 / 毛泽东思想 |
| 11-26 ~ 11-30 | p31–p35 | 会议大观（口诀 + 逐条）+ 其他 |
| 12-01 ~ 12-06 | p11–p22 | 第二轮回炉（每天 2 页，优先错题、会议、土地政策） |

每天的最小动作：

1. 打开“今日”，点“开始今天”。
2. 先只看标题回忆，卡壳按 `H` 看首字，不急着翻答案。
3. 揭晓后先看彩色关键词，再决定是否展开灰色解释。
4. 按真实感觉评分；忘记的卡会回到今天队列。
5. 背完一页即可停，不追加新页；有余力只回看错题。

## 4. 数据与代码

数据文件（构建期生成，静态托管）：

- `public/politics/data/points.json`：100 个知识点，含标题、板块、topic、页码、彩色 span。
- `public/politics/data/cards.json`：164 张卡；kind 为 `point | meeting | mnemonic | figure`。
- `public/politics/data/index.json`：100 行索引，供前端搜索。
- `public/politics/data/plan.json`：31 天计划。
- `public/politics/data/meta.json`：统计、板块、考试日。
- `public/politics/data/figures/timeline.png`：p18 史纲时间轴裁图。

抽取与构建脚本：

- `scripts/politics/extract.py`：PyMuPDF 按卡片框抽取，保留 span 颜色；p18 裁时间轴；跨页点合并。
- `scripts/politics/build_cards.py`：把 100 个点拆成 164 张卡；091 每 7 行口诀一张；092/093/094 按会议标题切卡；其余点每 8 块一张。

前端：

- `src/pages/politics.astro`
- `src/components/politics/{PoliticsApp,TodayPanel,StudySession,CardsPanel,LookupPanel,TopicsPanel,ProgressPanel,RichBlocks}.svelte`
- `src/lib/politics/{types.ts,data.ts,store.svelte.ts}`
- `src/styles/politics.css`
- 导航入口：`src/config/navBarConfig.ts` 的“背政治”

本地验证：

```bash
pnpm astro check
pnpm build
pnpm preview --host 127.0.0.1 --port 4321
```

## 5. 版权与边界

- 原 PDF 为第三方学习资料；本模块只做个人学习用的结构化改写，卡片保留原书关键词与记忆口诀，不替代原书。
- 页脚已标注蓝本来源；如公开传播，请保留“仅供个人学习、不替代原书”的说明。
- 模块不提供用户系统、不同步多端；所有记录只在本机浏览器。
- 题库只覆盖这本一页纸的 100 个知识点，不代替肖四、肖八、腿姐等冲刺资料。
